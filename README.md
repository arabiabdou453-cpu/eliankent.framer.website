## 🌟 Overview

**Elian Kent** is a high-performance, autonomous, and cinematic design portfolio built for modern digital creators, art directors, and agencies. Engineered with modern web standards, it delivers an uncompromising aesthetic with zero platform dependencies, instant first contentful paint (FCP), and fluid kinetic interactions.

---

## ⚡ Key Highlights

- **100% Autonomous & Self-Hosted**: Free from external platform locks, subscription walls, or third-party badge overlays.
- **Pixel-Perfect Fidelity**: Preserves every millimeter of editorial typography, subtle grid borders, and responsive alignments.
- **Cinematic Kinetic Motion**: Features interactive dual-span rolling hover typography, smooth reveal animations, and inertia-based scrolling.
- **Modern Asset Pipeline**: Utilizes pure **AVIF** and **WEBP** image formats with hardware-accelerated rendering.
- **Clean & Unbranded**: All watermarks, third-party analytics trackers, and marketplace badges have been completely removed.
- **Production-Grade Architecture**: Strict TypeScript compilation with zero compromises and lightning-fast Vite builds.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arabiabdou453-cpu/eliankent.framer.website.git
   cd eliankent.framer.website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` (or the terminal port) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The production-ready artifacts will be generated in the `dist/` directory.
